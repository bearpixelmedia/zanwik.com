# Zanwik.com

Marketing site for Zanwik, an AI consulting and implementation firm. Version **0.2.6**.

## Stack

- **Next.js 14** (App Router) — a catch-all route serves pre-rendered HTML
- Static pages under `frontend/content/mirror/`
- Assets under `frontend/public/assets/`
- Deploy: **Vercel** project `zanwik` (`frontend/vercel.json`), production host [www.zanwik.com](https://www.zanwik.com)

## Version

**0.2.6**

## Local development

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:3000
